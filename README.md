# АгроЭд

Сайт-витрина агротехнической продукции. Подробности: [docs/00-brief.md](docs/00-brief.md), статус: [docs/01-roadmap.md](docs/01-roadmap.md).

## Быстрый старт

Нужны Node.js 22+ и pnpm 11.

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

Остальные команды: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm generate`.

## Структура

```
apps/web    витрина на Nuxt
docs/       бриф, роадмап, ADR, спецификации, брендбук
```
