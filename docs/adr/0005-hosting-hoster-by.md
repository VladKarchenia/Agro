# ADR-0005: Хостинг на VPS hoster.by

- Статус: Принято
- Дата: 2026-10-27

## Контекст

Проект ориентирован только на Республику Беларусь, домен в зоне `.by`. Заказчик планирует хостинг на hoster.by.

## Решение

Размещаем на **VPS с root-доступом** на hoster.by. Обычный виртуальный хостинг не подходит: нужны Node.js (Nuxt SSR), PostgreSQL и Directus, удобнее всего через Docker.
Ориентировочный минимум для старта: 2 vCPU, 4 ГБ RAM (уточнить по факту нагрузки).

## Последствия

- Проверить, что на выбранном тарифе доступны Docker и root.
- Заявки содержат персональные данные, требования к их хранению учесть в спецификации заявок.
- Домен `agroed.by` пока не куплен.
