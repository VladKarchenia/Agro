# ADR-0006: Монорепозиторий на pnpm workspaces

- Статус: Принято
- Дата: 2026-10-27

## Контекст

Кроме витрины, в проекте ожидаются другие части: CMS (Directus), возможно отдельные сервисы и общие пакеты. Работаем в одном репозитории, код делим между людьми и агентами.

## Решение

Монорепозиторий на **pnpm workspaces** (без Turborepo/Nx, пока не нужны).

```
apps/web        витрина на Nuxt (@agroed/web)
apps/cms        Directus (появится на этапе с Docker)
docs/           документация
```

Общие инструменты (Biome, скрипты) лежат в корне. Версия pnpm зафиксирована в `packageManager`.

## Последствия

- Команды запускаются из корня: `pnpm dev`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm generate`.
- pnpm 11 не запускает скрипты сборки зависимостей без разрешения, разрешённые пакеты перечислены в `allowBuilds` в `pnpm-workspace.yaml`. При добавлении нового пакета с postinstall придётся вносить его туда.
