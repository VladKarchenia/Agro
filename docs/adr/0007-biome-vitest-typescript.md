# ADR-0007: Biome, Vitest и строгий TypeScript

- Статус: Принято
- Дата: 2026-10-27

## Контекст

Нужны быстрый линтер и форматтер, тесты там, где они имеют смысл, и строгая типизация.

## Решение

- **Biome 2** для линтинга и форматирования TS/JS/JSON/CSS/Vue. Стиль: пробелы, одинарные кавычки, без точек с запятой, ширина строки 100.
- **Vitest** для модульных тестов (`apps/web/tests/unit`). Тесты пишем там, где есть логика: утилиты, преобразование данных, правила SEO. Для компонентов и сценариев (корзина, заявка) позже добавим тесты компонентов и e2e.
- **TypeScript в строгом режиме**. Проверка типов: `nuxt typecheck` (vue-tsc).

## Ограничения, выявленные при настройке

1. **Biome видит только `<script>` и стили в `.vue`, а не `<template>`.** Из-за этого правила `noUnusedVariables` и `noUnusedImports` дают ложные срабатывания на импортах, используемых только в шаблоне. Для `*.vue` они отключены в `biome.json`. Шаблоны Vue Biome не проверяет. Если понадобится проверка шаблонов, добавим `@nuxt/eslint` только для `.vue`.
2. **TypeScript закреплён на 5.9.** `vue-tsc` 3.3 не работает с TypeScript 7 (нет `typescript/lib/tsc`). Вернуться к последней версии можно, когда `vue-tsc` это поддержит.
3. Markdown исключён из Biome (иначе он перестраивает таблицы в документации).
4. В `biome.json` комментарии не допускаются, объяснения лежат здесь.

## Последствия

- Команды: `pnpm lint`, `pnpm lint:fix`, `pnpm typecheck`, `pnpm test`.
- Все три проверки запускаются в CI и должны проходить перед деплоем демо.
