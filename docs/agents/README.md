# Правила для моделей и агентов

Этот каталог для договорённостей, по которым работают разные модели и агенты над проектом.

## Общие правила

1. Перед работой читать `CLAUDE.md`, `docs/00-brief.md`, релевантные ADR и спецификации.
2. Любое существенное решение сначала фиксируется в ADR, затем реализуется.
3. Функциональность описывается в спецификации до реализации.
4. Документация на русском, код и идентификаторы на английском.
5. Не придумывать данные о компании и товарах. Если данных нет, оставлять явную пометку.
6. Не коммитить секреты, `.env` не попадает в git.

## Планируемые файлы

- `code-style.md`: стиль кода, структура Nuxt-проекта
- `workflow.md`: как делим задачи и оформляем результаты
