# SEO-чек-лист для разработчиков и агентов

SEO главная цель проекта. Правила и обоснования: [docs/specs/seo.md](../specs/seo.md). Этот файл короткий список «что сделать при изменении».

## Перед коммитом

```bash
pnpm lint && pnpm typecheck && pnpm test      # в тестах уже есть SEO-проверки
pnpm generate && pnpm seo:audit               # аудит итогового HTML (режим production)
```

Локально на Windows перед повторной сборкой удалить `apps/web/node_modules/.cache` и `apps/web/.output`.
Для демо-режима: `NUXT_PUBLIC_SITE_ENV=demo NUXT_APP_BASE_URL=/Agro/ NUXT_PUBLIC_SITE_URL=<адрес демо>` и `pnpm seo:audit --mode demo --site-url <адрес демо>`.

## Я добавляю новую страницу

- [ ] В `app/pages/...` вызван `usePageSeo({ title, description, breadcrumbs?, jsonLd? })`. Прямых `useSeoMeta` и `useHead` нет.
- [ ] Статическая страница добавлена в `STATIC_PAGES` (`app/seo/entries.ts`), с `indexable: true` или с `indexable: false` и причиной (`reason`).
- [ ] Динамический раздел добавлен в `getCatalogPaths()` или аналог, чтобы попасть в sitemap и llms.txt, и в список в `seo-coverage.test.ts`.
- [ ] Один `h1`, осмысленный `title` (до 70 символов) и `description` (50–170), уникальные.
- [ ] Если страница индексируемая: хлебные крошки (`breadcrumbs`) и подходящая разметка (Product, CollectionPage, FAQPage…) из `utils/structured-data.ts`.
- [ ] Страница-заглушка без содержимого остаётся `indexable: false`.
- [ ] Ссылки между страницами без завершающего слеша, `NuxtLink`, а не `<a href>`.

## Я меняю данные каталога (категории, товары, CMS)

- [ ] Адреса остаются в формате `/catalog/<категория>/<товар>`, slug в нижнем регистре через дефис, не меняются без редиректа 301 со старого адреса.
- [ ] Описание товара начинается с названия и уникально. Выдуманных характеристик, цен, отзывов и рейтингов нет.
- [ ] Если нет реального фото, `image` в разметке не заполняется.
- [ ] После изменения: `pnpm generate && pnpm seo:audit`.

## Я добавляю фильтры, сортировку, пагинацию

- [ ] Адреса с параметрами не индексируются: canonical на категорию без параметров, `noindex, follow`, не в sitemap.
- [ ] Индексируемая подборка оформлена отдельной посадочной страницей с чистым адресом и уникальным текстом, внесена в реестр.

## Я меняю шаблоны, шапку, подвал, мета-теги

- [ ] Ничего не дублирую вручную: мета-теги формируются только в `usePageSeo`.
- [ ] Картинки с `alt`, `target="_blank"` с `rel="noopener"`.
- [ ] Не ломаю SSR: контент и разметка есть в HTML ответа сервера, а не появляются только после запуска JavaScript.

## Я меняю robots, sitemap, llms.txt, ИИ-ботов

- [ ] Правка в `app/seo/*` и тесте `seo-files.test.ts`, а не в сгенерированных файлах.
- [ ] Поисковые и пользовательские ИИ-боты остаются разрешёнными, политику обучающих ботов меняет только заказчик (`aiTrainingCrawlers`).

## Если аудит упал

Читайте сообщение: оно называет страницу и правило. Чините причину, а не правило. Если правило действительно устарело, измените его в `scripts/seo-audit.mjs` и в `docs/specs/seo.md` одним коммитом и объясните почему.
