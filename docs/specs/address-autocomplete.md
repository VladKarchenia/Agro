# Спецификация: подсказки адреса по Беларуси

Статус: исследование, решение не принято. Дата: 2026-10-31.

## Запрос

В поле «Город или адрес доставки» подключить автокомплит по Беларуси, хотя бы до улицы включительно, без номера дома.

## Главное

Готовой «библиотеки автокомплита по РБ» с данными нет. Любой автокомплит состоит из **компонента интерфейса** (его мы напишем сами, это несложно) и **источника данных об адресах** (это и есть вопрос). Источник данных определяет цену, юридические риски и то, будет ли это работать на статичном демо.

## Варианты источника данных

| Вариант | Данные по Беларуси | Цена | Риски и ограничения |
|---|---|---|---|
| **Яндекс Геосаджест** | Заявлены «адреса в России и СНГ», покрытие именно Беларуси и улиц нужно проверять | Бесплатный лимит небольшой (порядка 1000 запросов в сутки по документации 2025 года), платные лицензии начинаются от 180 000 ₽ в год | Ключ и договор с Яндексом. Фрагменты адреса уходят в Яндекс (РФ): трансграничная передача, нужна запись в политике и согласие. Условия для Беларуси не уточнены |
| **Google Places Autocomplete** | Хорошее | Платно по сессиям, нужна платёжная карта Google Cloud | Оформление биллинга из РБ может быть невозможно, передача в США. Не проверялось |
| **Nominatim (публичный сервер OSM)** | Данные OSM | Бесплатно | **Автокомплит запрещён политикой использования**, лимит 1 запрос в секунду. Не подходит |
| **Photon (публичный сервер komoot)** | Данные OSM | Бесплатно | Сервер демонстрационный: «разумные объёмы», без гарантий, не для коммерческого использования, могут ограничить или заблокировать. Данные уходят в Германию. Для продакшена не подходит |
| **Photon на собственном сервере** | Данные OSM | Бесплатно, но нужен сервер (Java и OpenSearch, ориентировочно от 2 ГБ RAM для страны) | Нужно настроить и поддерживать. Данные никому не передаются. Качество зависит от полноты OSM |
| **Собственная база из OSM** (PostgreSQL + поиск по триграммам, наш эндпоинт `/api/address/suggest`) | Данные OSM (лицензия ODbL, нужна ссылка на источник) | Бесплатно | Нужен бэкенд и разовый импорт. Данные никому не передаются. Качество зависит от полноты OSM |
| **Статические файлы из OSM** (список населённых пунктов и по файлу улиц на каждый город, загружаются в браузер по мере необходимости) | Данные OSM (ODbL) | Бесплатно | Работает **без сервера**, в том числе на демо GitHub Pages. Подходит для городов, улицы в деревнях в OSM часто не размечены. Данные нужно периодически пересобирать |

Источники: [Photon (komoot)](https://github.com/komoot/photon), [обсуждение о коммерческом использовании](https://github.com/komoot/photon/discussions/598), [Яндекс Геосаджест](https://yandex.ru/maps-api/products/suggest-api), политика использования Nominatim ([operations.osmfoundation.org](https://operations.osmfoundation.org/policies/nominatim/)).

## Что мешает сделать это прямо сейчас

- Данные OSM для Беларуси я пытался получить через Overpass API, но с рабочей машины он недоступен (ошибка TLS, таймауты). Альтернатива, выгрузка страны с Geofabrik (файл порядка сотен мегабайт) и её обработка, возможна, но это отдельная задача, а не правка поля.
- В OSM в Беларуси названия часто на белорусском языке, русские (`name:ru`) есть не везде. Качество и полноту русских названий нужно проверить на реальной выборке до принятия решения.

## Рекомендация

Двухэтапно, без платных сервисов и передачи адресов третьим лицам:

1. **Этап А, на демо:** статический список населённых пунктов Беларуси из OSM (город, посёлок, деревня с областью и районом) и компонент подсказок в поле. Работает на GitHub Pages, ничего не отправляется наружу.
2. **Этап Б, вместе с бэкендом:** улицы через собственный эндпоинт на базе OSM в PostgreSQL (или статические файлы улиц по крупным городам), пока бэкенда нет.

Разделить поле на два: **«Населённый пункт»** (подсказки) и **«Улица, дом, офис»** (подсказки улиц после выбора города, дом и квартира вводятся вручную). Подсказки лишь помогают: пользователь всегда может ввести свой вариант.

## Что нужно от заказчика

- Подтвердить, что принимаем подход «данные OSM, без Яндекса и Google».
- Определить, насколько важна точность адреса для менеджеров: достаточно «город + свободный текст» или нужна структурированная улица.
- Если заказчик всё же хочет Яндекс Геосаджест или другой платный сервис, нужны ключ, договор и обновление политики (трансграничная передача).

## Реализация (когда решение принято)

- Компонент `AddressSuggest.vue`: combobox по WAI-ARIA (роли `combobox` и `listbox`, управление стрелками, Enter и Escape, подсказки не мешают свободному вводу), независимый от источника данных.
- Источник за интерфейсом `suggest(query, context)`, чтобы менять статику на API без правок интерфейса.
- Поиск с учётом `ё/е`, регистра и раскладки, задержка перед запросом (debounce).
- Атрибуция «© участники OpenStreetMap» рядом с подсказками (лицензия ODbL).
- Модульные тесты на поиск, e2e на клавиатурное управление.
