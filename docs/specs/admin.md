# Спецификация: админка и роли

Статус: черновик. Дата: 2026-10-28.

## Цель

Админка (предварительно Directus, ADR-0002) для работы с каталогом, страницами и заявками. Пользователей около 5, ролей две.

## Роли

| Возможность | Админ | Менеджер |
|---|---|---|
| Заявки: просмотр, смена статуса, комментарии | да | да |
| Каталог: товары, фото, характеристики | да | да |
| Каталог: публикация товаров | да | да (решено: всё, кроме настроек и пользователей) |
| Структура категорий и набор характеристик | да | да |
| Информационные страницы | да | да |
| Импорт каталога | да | да |
| Настройки сайта (контакты компании, SEO-настройки, интеграции) | да | нет |
| Пользователи и роли | да | нет |
| Удаление данных | да | требует уточнения |

## Правила

- Менеджер не видит и не меняет настройки интеграций (токен Telegram-бота и т. п.) и список пользователей.
- Рекомендуется «мягкое» удаление (скрытие) товаров и категорий вместо физического, чтобы не ломать ссылки из заявок и SEO-адреса. Перед удалением опубликованной категории или товара должен быть настроен редирект.
- Действия над заявками и каталогом журналируются (кто и когда изменил).
- Вход в админку защищён: надёжные пароли, при возможности двухфакторная аутентификация для админов.

## Открытые вопросы

- Может ли менеджер физически удалять товары, или только скрывать?
- Нужны ли менеджеру разные права на заявки (например, видеть только назначенные ему)?
- Нужна ли двухфакторная аутентификация обязательно для всех или только для админов?
- Проверить в Directus: реализуемость ролей без платных тарифов и журналирование изменений (ADR-0002).
