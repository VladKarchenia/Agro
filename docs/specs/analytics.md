# Спецификация: аналитика, cookie и поисковые инструменты

Статус: черновик. Дата: 2026-10-28.

## Решения заказчика

- Подключаем **Яндекс Метрику** и **Google Analytics 4**.
- Аккаунты заводим новые (владельца и доступы определим при создании).
- Нужен **баннер согласия на cookie**.
- **Google Search Console** и **Яндекс Вебмастер** подключаем в конце, перед запуском на боевом домене.

## Cookie-баннер и согласие

- Скрипты Метрики и GA4 **не загружаются, пока посетитель не согласился** на аналитические cookie. До согласия не отправляется ничего, включая идентификаторы.
- Категории: **необходимые** (работа сайта, запоминание выбора, корзина) включены всегда, **аналитические** включаются по согласию.
- Баннер: кнопки «Принять» и «Отклонить» одинаково заметны, ссылка на раздел о cookie в [политике](legal-privacy.md). Выбор можно изменить позже (ссылка «Настройки cookie» в подвале).
- Выбор хранится в браузере (cookie или localStorage) с датой и версией текста. Баннер повторно показывается при изменении перечня сервисов.
- Баннер не должен ломать SEO и скорость: не блокирует отрисовку, не смещает вёрстку (CLS), не закрывает основной контент на мобильных.

## Подключение

- Загрузка скриптов только на клиенте и только после согласия, с отложенной загрузкой (после интерактивности), чтобы не ухудшать Core Web Vitals.
- Идентификаторы счётчиков (`NUXT_PUBLIC_GA_ID`, `NUXT_PUBLIC_YM_ID`) задаются переменными окружения.
- **В демо-сборке (GitHub Pages) и локально аналитика отключена**, чтобы не засорять данные. Включается только для боевого домена.
- События, которые стоит отправлять: просмотр страницы, добавление в заявку, отправка заявки (цель/конверсия), клик по телефону и Telegram-ссылкам, использование фильтров. Список уточним после готовности каталога.
- Яндекс Метрика: вебвизор и запись форм **выключены по умолчанию** (риск попадания персональных данных в записи). Включение только после решения заказчика и обновления политики.

## Персональные данные и трансграничная передача

Google Analytics (Google LLC, США) и Яндекс Метрика (ООО «Яндекс», РФ) обрабатывают данные за пределами Беларуси. По статье 9 Закона 99-З это допустимо в страны с надлежащим уровнем защиты либо при согласии посетителя после информирования о рисках. Перечень стран определяет НЦЗПД, актуальный список нужно сверить до запуска. Поэтому:
- Аналитика включается только по согласию (см. выше).
- В политике указаны сервисы, страны и риски.
- Подробности и чек-лист: [legal-privacy.md](legal-privacy.md).

## Поисковые инструменты (в конце, перед запуском)

| Инструмент | Что делаем | Зависит от |
|---|---|---|
| Google Search Console | Подтверждение домена (DNS-запись), отправка `sitemap.xml`, проверка индексации и Core Web Vitals | Купленный домен, боевой сервер |
| Яндекс Вебмастер | Подтверждение прав, `sitemap.xml`, регион сайта (Беларусь), проверка индексации | Купленный домен, боевой сервер |
| Bing Webmaster Tools | Импорт из Search Console, полезен для ИИ-поиска и ассистентов, которые используют индекс Bing | Search Console |

Сначала закрываем технику (sitemap, robots, canonical, schema.org, скорость), только потом отправляем сайт на индексацию.

## Не входит в старт

Сквозная аналитика, CRM-интеграции, A/B-тесты, ретаргетинг.

## Открытые вопросы

- Кто владелец аккаунтов Метрики и GA4 (юрлицо компании или личный аккаунт) и кто получает доступ?
- Нужен ли вебвизор Метрики (повышает риски по персональным данным)?
- Какие конверсии важны бизнесу (отправка заявки, звонок, переход в Telegram)?
- Проверить актуальный перечень стран с надлежащей защитой (НЦЗПД) и решить, достаточно ли согласия для GA4.
