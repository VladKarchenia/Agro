# Спецификации

Здесь лежат спецификации функций сайта. Один файл = одна функция или область, например:

- `data-model.md`: модель данных
- `seo.md`: SEO-стратегия (Google, Яндекс, ИИ)
- `catalog.md`: каталог, фильтры, сортировки
- `cart-and-order.md`: корзина и заявка
- `admin.md`: админка и роли
- `account.md`: личный кабинет (этап 2)

Шаблон файла: цель, пользовательские сценарии, требования, данные, критерии приёмки, открытые вопросы.
Спецификации пишем до реализации и обновляем, если реализация меняет договорённости.
