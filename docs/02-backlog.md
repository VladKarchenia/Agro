# Бэклог и идеи на развитие

Идеи, которые не входят в ближайшие этапы, но не должны потеряться. Перед реализацией каждая оформляется спецификацией.

| Идея | Зачем | Источник |
|---|---|---|
| Статьи и блог | Информационные запросы, трафик из Google, цитирование ИИ-поиском: как выбрать технику, сравнения, инструкции | Решение заказчика, 2026-10-28 |
| Блок «С этим товаром покупают» на карточке | Нужны реальные связи товаров от заказчика (какой кабель берут вместе с чем), выдумывать нельзя. «Другие типоразмеры» и «Ещё в категории» уже сделаны | `03-competitor-analysis.md` |
| Страницы «Сертификаты», «Гарантия и возврат», конкретные условия «Доставки и оплаты» | Доверие и ответы на частые вопросы; сильные конкуренты показывают цифры и документы | `03-competitor-analysis.md` |
| Посадочные страницы по сечению, числу жил и бренду | Запросы вида «кабель ВВГнг 3х2,5»; так делают prokabel.by, tok.by | `03-competitor-analysis.md` |
| Оптовые условия: таблица скидок, запрос предложения | B2B-покупатели; так делают elswi.by, emplus.by | `03-competitor-analysis.md` |
| Платный сервис позиций (Serpstat, Topvisor) | Реальные позиции конкурентов вместо наблюдений | `03-competitor-analysis.md` |
| Личный кабинет: история заказов и повтор заказа | Удобство постоянных клиентов | Бриф |
| Резервный канал уведомлений по email | Дублирование Telegram | `specs/cart-and-order.md` |
| Подсказки адреса по Беларуси (на данных OpenStreetMap) | Меньше ошибок в адресах заявок, удобнее ввод. Ждёт решения по источнику данных | `specs/address-autocomplete.md` |
| Ручная проверка доступности со скринридером (NVDA, VoiceOver) перед запуском | Автоматика находит только часть проблем | `specs/accessibility.md` |
| Сквозные тесты с настоящим приёмом заявки на тестовой БД | Когда появится бэкенд (`orderMode: api`) | ADR-0010, ADR-0012 |
