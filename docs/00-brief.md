# Бриф проекта «АгроЭд»

Статус: черновик, дополняется по мере обсуждений. Дата создания: 2026-10-27.

## Суть

Сайт-витрина агротехнической продукции и товаров для сельского хозяйства компании **АгроЭд**.
Референсы по нише: elos-by.com, elswi.by.

## Главная цель

Сайт, который хорошо продвигается в поисковой выдаче: **Google (приоритет 1), ИИ-поиск и ассистенты (приоритет 1), Яндекс (приоритет 2)**.
Из этого следует: серверный рендеринг, чистые URL, структурированные данные, быстрая загрузка, уникальный контент.

## Рамки

| Параметр | Решение |
|---|---|
| Язык | Только русский |
| Рынок | Только Республика Беларусь |
| Домен | `agroed.by` (предварительно, ещё не куплен) |
| Цены | Не показываем, «цена по запросу» (витрина, указывать цены нельзя) |
| Хостинг | hoster.by, нужен VPS с root-доступом (проверить тариф) |
| Каталог | Старт 500–800 товаров, максимум 1500–3000 |
| Структура каталога | Категории → подкатегории → карточки товаров |
| Родитель товара | У товара всегда одна основная категория (один адрес, без дублей) |
| Карточка товара | Одно и более фото, описание, характеристики (разные у разных категорий) |
| Фильтры и сортировки | В категориях, по характеристикам. Набор фильтров пока неизвестен |

## Качество и процесс

- Сайт полноценно работает на **десктопе и мобильных** (mobile-first вёрстка, проверка на ширине около 390 px и на десктопе).
- Тесты пишем там, где они имеют смысл (логика, данные, ключевые сценарии), см. ADR-0007.
- Актуальное демо публикуется на GitHub Pages, закрыто от индексации, см. ADR-0008.

## Функциональность

### Этап 1 (витрина)
- Каталог с деревом категорий, фильтрами и сортировками
- Карточка товара
- Корзина без авторизации
- Оформление заказа как **заявки**: данные клиента → заявка уходит в компанию → менеджер подтверждает → оплата и доставка оформляются отдельно, вне сайта
- Информационные страницы (о компании, контакты, доставка и т. д.)
- Админка: каталог, заказы. Роли: **админ** и **менеджер**, около 5 пользователей
- Уведомления о новой заявке: админка + Telegram или почта

### Этап 2 (позже)
- Личный кабинет покупателя: история заказов, повтор заказа

## Наполнение каталога

Планируется импорт данных с существующих сайтов (структура, названия, характеристики, артикулы).
Описания и фото нужно делать уникальными или брать у производителей: дубли и чужие материалы вредят SEO и создают риск по авторским правам.

## Принципы работы

- Всё фиксируем в документах: решения в `docs/adr/`, спецификации в `docs/specs/`, брендбук в `docs/brand/`.
- Документация на русском.
- Сайт начинаем как «скорлупу» и наращиваем.
- Задачи по мере необходимости делятся между моделями и агентами, правила в `docs/agents/`.
