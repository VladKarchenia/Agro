- Куплен ли домен `agroed.by`
- Юридические требования по персональным данным в заявках (РБ)
- Список категорий и набор фильтров
- Источники для импорта каталога и правила работы с чужим контентом

- Политика для обучающих ИИ-ботов, семантическое ядро, домен с `www` или без (см. `specs/seo.md`)
